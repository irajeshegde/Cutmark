# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

**Our standard.** Be respectful and constructive. Welcome newcomers. Give and accept feedback graciously. Focus on what is best for the project and its users.

**Not acceptable.** Harassment, discrimination, insults, personal attacks, trolling, publishing others' private information, or any conduct that would reasonably be considered inappropriate in a professional setting.

**Enforcement.** Maintainers may edit or remove comments, issues and pull requests that violate this code, and may ban contributors who repeatedly or seriously do so. To report a problem, open a private security/contact request through the repository owner's GitHub profile, or contact the maintainer directly.

This applies in all project spaces: issues, pull requests, discussions and reviews.
